Lab File Server

PXE boot assets — ISO images, kernels, initrds, root filesystems and iPXE scripts. Click a file to download it, or copy its URL for a boot entry.

Uploads and boot menus are managed by the iPXE Manager (port 8091 by default), which writes into ./data/webfs_share — this server only reads it. You can also copy files straight into that directory on the host.
